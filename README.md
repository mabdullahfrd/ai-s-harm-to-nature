## Overview

Artificial Intelligence is transforming the world at an unprecedented pace.

Every prompt, generated image, video, and model training run requires enormous computing infrastructure powered by electricity, water, and data centers. While AI continues to unlock incredible possibilities, its environmental footprint often remains invisible to everyday users.

**AI & Nature's Cost** is an educational web experience designed to make those hidden costs visible through storytelling, interactive visuals, and data-driven insights.

Instead of presenting dry statistics, the experience combines cinematic design, smooth interactions, and environmental data to encourage more responsible AI usage.

---

## Why This Project Exists

Most people understand the benefits of AI.

Very few understand the resources required behind every interaction.

This project explores questions such as:

- How much electricity powers modern AI?
- Why do AI data centers consume so much water?
- What happens as AI adoption continues to grow?
- How can users reduce unnecessary AI waste?

The goal is **awareness, not fear.**

AI is an incredible technology.

Responsible AI is even better.

# Design Philosophy

The project intentionally avoids a traditional dashboard style.

Instead, it adopts a cinematic storytelling approach inspired by modern documentary experiences.

Design principles include:

- High contrast
- Minimal distractions
- Immersive motion
- Large typography
- Atmospheric backgrounds
- Smooth transitions
- Focused reading experience

The objective is to communicate information emotionally without sacrificing accuracy.

# Running Locally

Watch the live DEMO AT(https://ai-s-harm-to-nature.vercel.app/)

Clone the repository.
```bash
git clone https://github.com/yourusername/ai-s-harm-to-nature.git
```

Install dependencies.

```bash
npm install
```

Start the development server.

```bash
npm run dev
```

Build for production.

```bash
npm run build
```

Preview production build.

```bash
npm run preview
```
